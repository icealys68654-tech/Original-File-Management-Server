# C4 architecture model

`c4-model.json` is the machine-readable source of truth. `c4-context.mmd` is a Mermaid C4Context diagram suitable for GitHub Markdown rendering. Run `node tools/c4-validate.mjs` to validate unique element IDs, relationship endpoints, labels and diagram references.

The diagram is a context-level view; the model also records selected containers. It is not a full C4 Level 2/3 decomposition or a claim of external architecture certification.
