Encrypted upload

Files are encrypted using AES-256-GCM. The file key is wrapped separately for your account and every selected recipient using RSA-OAEP-SHA256. Recipient envelopes are mandatory.

Files and permissions

“Copy access link” is for signed-in users with existing permission. “Create public preview link” makes a separate 7-day bearer link that anyone can open without signing in. The owner’s private key is read locally in your browser and never uploaded; the URL fragment carries the decryption key and is visible to anyone who receives the complete link. Preview links do not grant account permissions.

Select your backed-up cfs-private-key.pem, then use “Create public preview link” beside an owned file. Supported previews: raster images and common text files. PDFs and other formats are not rendered here, to avoid exposing browser download controls. Revoking a link blocks future retrieval, but cannot erase content already viewed, copied, or captured.
